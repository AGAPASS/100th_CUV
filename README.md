## 项目简介

这是一个以横向历史长卷呈现的互动网页专题。从古代丝绸之路、景教入华，到明清时期的中西交流、近代新教传播与中文圣经翻译，访客可以在画卷中自由移动，并通过 24 个历史热点阅读相应的图文介绍。

项目采用纯 HTML、CSS 和 JavaScript 实现，不依赖前端框架或构建工具。

## 体验方式

1. 进入页面后点击“启卷探索”。
2. 在桌面端拖动画卷、滚动鼠标滚轮，或使用方向键浏览时间线；在移动端左右滑动即可浏览。
3. 点击画卷中的编号光点，打开对应历史事件的详情图片。
4. 使用底部进度条快速定位，或点击回到起点按钮重新浏览。
5. 背景音乐会在启卷后播放，也可以通过右上角按钮随时暂停或继续。

## 主要特点

- **自由探索**：进入画卷后不自动滚动，浏览节奏完全由访客控制。
- **24 个历史热点**：热点位置依据设计标注图校准，覆盖重要人物、事件与译本。
- **长卷式叙事**：完整保留横幅画面的上下内容，并根据屏幕高度等比呈现。
- **图文详情**：点击热点后以居中弹窗展示介绍，较长内容支持滚动阅读。
- **加载优化**：详情图使用 WebP，并根据当前位置预加载附近热点素材。
- **移动端适配**：支持横竖屏、触控滑动、详情平移和动态视口高度。
- **键盘与动效适配**：支持方向键、Page Up/Down、Home/End，并尊重系统的“减少动态效果”设置。
